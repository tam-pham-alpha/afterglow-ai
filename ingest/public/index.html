Admin gate. Instruction, seed, map, and the GitHub App connection. Events still land on observer. Agents ask memory through MCP.

Connect creates a GitHub App for this instance. Credentials stay in .data/github.json, not in memory. Observer reads the same file. Local webhooks go through a smee.io channel so GitHub can reach your machine. If GitHub shows a 500 after Create, refresh github.com/settings/apps. The one-time code is gone — paste App ID, webhook secret, and the private key from that app, or Connect again.
