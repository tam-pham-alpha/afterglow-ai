# `_docs/` — log khi xây Afterglow

Folder này không phải trí nhớ tổ chức. Org không fork rồi đổ ADR / instruction của công ty họ vào đây.

Trí nhớ vận hành sống trong store, vào qua **ingest** và **observer**. Landing công khai nằm ở `docs/` (GitHub Pages).

`_docs/` là chỗ **developer của repo upstream** ghi trong lúc phát triển: kế hoạch, ADR, nhật ký quyết định kỹ thuật, note debug. Fork bỏ qua. Dated file: `YY-MM-DD-<slug>.md`.
