# `_docs/` — chỉ khi xây Afterglow

Folder này không phải trí nhớ tổ chức. Org không fork rồi đổ ADR / instruction vào đây.

Trí nhớ sống trong store, vào qua **ingest** và **observer**. Landing công khai nằm ở `docs/` (GitHub Pages).

`_docs/` chỉ chứa kế hoạch / ADR của repo upstream. Fork bỏ qua. Dated plan: `YY-MM-DD-<slug>.md`.
